SENTIA TILES -> APPLE LOGIC PRO MIDI MAP
========================================
All CC and channel numbers use standard 1-based MIDI channels (Ch 1..16).
Virtual CoreMIDI endpoints created by tiles-logic-bridge:
  - TILES Logic MPE     (MPE Lower Zone: Ch 1 Master, Ch 2..9 Members)
  - TILES Logic MCU     (Mackie Control Universal bidirectional surface)
  - TILES Logic Grid    (Smart Controls, Auto-Assign, Live Loops, Haptics)
  - TILES Logic Display (Melodic LED echo: Ch 1 Green, Ch 2 Soft Red)


1. SMART CONTROLS & MACKIE V-POTS (Page 2: Smart Controls)
----------------------------------------------------------
Port: TILES Logic Grid (Channel 16) + TILES Logic MCU (Channel 1)

  Pad (Col,Row)  Control Name         Grid Learn CC   MCU V-Pot ID   Action / Feedback
  -------------  -------------------  --------------  -------------  ----------------------------
  (1, 1) / (1,3) Smart Control 1      CC 102 (Ch 16)  0x10 / 0x30    Row 1: +6 / Row 3: -6, LED ring
  (2, 1) / (2,3) Smart Control 2      CC 103 (Ch 16)  0x11 / 0x31    Row 1: +6 / Row 3: -6, LED ring
  (3, 1) / (3,3) Smart Control 3      CC 104 (Ch 16)  0x12 / 0x32    Row 1: +6 / Row 3: -6, LED ring
  (4, 1) / (4,3) Smart Control 4      CC 105 (Ch 16)  0x13 / 0x33    Row 1: +6 / Row 3: -6, LED ring
  (1, 2) / (1,4) Smart Control 5      CC 106 (Ch 16)  0x14 / 0x34    Row 2: +6 / Row 4: -6, LED ring
  (2, 2) / (2,4) Smart Control 6      CC 107 (Ch 16)  0x15 / 0x35    Row 2: +6 / Row 4: -6, LED ring
  (3, 2) / (3,4) Smart Control 7      CC 108 (Ch 16)  0x16 / 0x36    Row 2: +6 / Row 4: -6, LED ring
  (4, 2) / (4,4) Smart Control 8      CC 109 (Ch 16)  0x17 / 0x37    Row 2: +6 / Row 4: -6, LED ring

  Mackie Assignment Modes (Column 5):
    Pad (5, 1) -> Note 0x2B (Plug-In / Smart Control)
    Pad (5, 2) -> Note 0x2A (Pan)
    Pad (5, 3) -> Note 0x29 (Send)
    Pad (5, 4) -> Note 0x28 (Track)

  Midpoint Detent Haptic Cue:
    Feedback arriving on Grid Ch 16 CC 102..109 (values 62..66) or MCU V-Pot
    ring 5..6 triggers a synchronized 65 ms detent haptic pulse on the matching pad.


2. PER-PAD EXPRESSION (Touch, Strike, Press, Tilt)
--------------------------------------------------
A. Native MPE Stream (SENTIA TILES N MIDI / TILES Logic MPE):
  Ch 1 (Master):     CC 64 Sustain Pedal, RPN 0x0006 (MPE Lower Zone = 8 ch)
  Ch 2..9 (Members): Note-On (Strike velocity 1..127), Note-Off (Touch release),
                     Channel Pressure 0xDn (Z-axis Press 0..127),
                     14-bit Pitch Bend 0xEn (Y-axis Tilt, +/-48 st / centered)

B. Focused-Pad Auto-Assign CCs (TILES Logic Grid, Channel 16 - Cmd+L Learn):
  CC 20 -> Strike (Note-On velocity, 1..127)
  CC 21 -> Press  (Channel Pressure, 0..127)
  CC 22 -> Tilt   (Y-axis Pitch Bend normalized, 0..127, center 64)
  CC 23 -> Touch  (Capacitive Touch Gate: 127 touched, 0 released)

C. Polyphonic Per-Voice Expression CCs (TILES Logic Grid, Channels 2..9):
  CC 14 -> Per-Voice Strike (1..127)
  CC 15 -> Per-Voice Press  (0..127)
  CC 16 -> Per-Voice Tilt   (0..127)
  CC 17 -> Per-Voice Touch  (127 / 0)

D. Expression Splitter & Console Logger Switches (TILES Logic Grid, Channel 1):
  CC 118 -> Value 0 disables Auto-Assign expression splitting; 1..127 enables it.
            (Also toggled by Smart Controls Pad (6, 4).)
  CC 85  -> Value 1..127 enables MIDILogger real-time console output; 0 disables it.
  CC 86  -> MIDILogger category filter (0 All, 1 MPE, 2 Haptic, 3 Grid, 4 MCU).


3. HAPTIC INTENSITY & SYNCHRONIZED HAPTIC CUES
----------------------------------------------
Port: TILES Logic Grid (Channel 1) -> StudioLink -> SENTIA TILES DAW (SysEx 0x10/0x11)

  CC 115 -> Synchronized Haptic Intensity (0 = muted, 1..127 scales pulse
            duration 20..500 ms around 65 ms nominal; default 100)
  CC 116 -> Smart Control Detent Sync Cue (value 1..8 pulses macro pad 1..8)
  CC 117 -> Direct Pad Haptic Cue (value 1..24 pulses pad 1..24;
            127 pulses all pads; 0 clears active pulses immediately)
  0xF8   -> Realtime MIDI Clock (24 PPQ): pulses triggered Live Loops scene
            pads in quarter-note lock when quantized sync is active.

Hardware Touch & Play Haptics (Firmware op_mode.c via SysEx 0x10):
  Flag bit 0x01 (HAS_CLIP):   56 ms sharp touch kick when finger lands on pad
  Flag bit 0x02 (IS_PLAYING): Continuous level-90 sustain buzz while held


4. MIXER BANK NAVIGATION & TRACK STRIPS (Page 3: Mixer)
-------------------------------------------------------
A. Track Window & Bank Navigation:
  SENTIA TILES DAW  Ch 1, CC 106 -> Hardware "-" / "+" Track Offset (0..59),
                                    auto-aligns Mackie 8-channel banks (0x2E/0x2F)
  TILES Logic Grid  Ch 1, CC 112 -> Fader Group LED Color Palette (0..5:
                                    Periwinkle, Teal, Amber, Gold, Coral, Magenta)
  TILES Logic Grid  Ch 1, CC 113 -> Active Mixer Bank / Fader Group (0..11 ->
                                    track offset bank * 5, updates hardware LED color)
  TILES Logic Grid  Ch 1, CC 114 -> Mixer Bank Step: 0..63 steps -5 tracks,
                                    64..127 steps +5 tracks + aligns MCU bank
  TILES Logic Grid  Ch 16, CC 32..36 -> Per-Fader Group LED Color Hint (Cols 1..5)
  TILES Logic Grid  Ch 1, CC 119 -> Bridge Page Select:
                                    0 = Live Loops, 1 = Smart Controls,
                                    2 = Mixer, 127 = Cycle next page
  Double-Tap Circle+Diamond     -> DAW Ch 1 CC 105 (within 450 ms) cycles page

B. Mackie Control Strip & Navigation Notes (TILES Logic MCU, Channel 1):
  Note 0x2E -> Bank Left  (-8 tracks)
  Note 0x2F -> Bank Right (+8 tracks)
  Note 0x30 -> Channel Left  (-1 track, Mixer Pad (6, 2))
  Note 0x31 -> Channel Right (+1 track, Mixer Pad (6, 3))
  Note 0x56 -> Logic Cycle On/Off (Mixer Pad (6, 4))

C. Visible 5-Track Mixer Pad Matrix (Columns 1..5 -> abs_track % 8):
  Row 1 -> Mute     (MCU Note 0x10..0x17, Amber LED feedback)
  Row 2 -> Solo     (MCU Note 0x08..0x0F, Gold LED feedback)
  Row 3 -> Rec Arm  (MCU Note 0x00..0x07, Coral LED feedback)
  Row 4 -> Select   (MCU Note 0x18..0x1F, Sentia Magenta LED feedback)


5. TRANSPORT & LIVE LOOPS MATRIX (Page 1: Live Loops)
-----------------------------------------------------
Hardware DAW CCs (SENTIA TILES N DAW, Channel 1):
  CC 102 -> Play (MCU Note 0x5E; ignored while playing in Performance layout)
  CC 103 -> Stop (MCU Note 0x5D + disarms record)
  CC 104 -> Record (MCU Note 0x5F; 2 s Diamond hold)
  CC 105 -> Master Stop (Circle+Diamond) -> Grid Ch 16 CC 29
  CC 107 -> End Capture -> Grid Ch 16 CC 30
  CC 108 -> Cell/Scene Pressure Click (1..24) -> Grid Ch 16 CC 24 + Notes 36..55
  CC 109 -> Cell Stop (1..24) -> Grid Ch 16 CC 25
  CC 110 -> Cell Delete, Circle + 3 s Touch (1..24) -> Grid Ch 16 CC 27
  CC 111 -> Exclusive Rec Arm + Melodic Capture (1..24) -> Grid Ch 16 CC 26 + SysEx 0x12
  CC 28  -> Scene Fire (Column 6 rows 1..4 -> Logic Grid Ch 16, values 1..4)
