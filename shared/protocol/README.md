# protocol/

Will hold the formal definition of the USB vendor interface protocol used
by `firmware/src/usb_vendor/` and `companion-app/src/main/`: message IDs,
packet/framing format, versioning strategy, and the message catalog
(remap, calibration capture, live sensor streaming, diagnostics, profile
read/write, firmware update).

Not authored yet — see `docs/protocol/README.md` for design notes leading
up to this.
