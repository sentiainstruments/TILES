# Quick start guide

The TILES quick start guide lives in its own repo and is published as a website:

- **Live:** https://start.sentiainstruments.com
- **Source:** https://github.com/Mats2000/TILES_QuickStart (static HTML, deployed by
  Vercel on every push to `main`)

It moved there from this folder on 2026-09-30 so the guide has one home with its own
deploy lifecycle, separate from firmware. When a firmware change alters controls,
modes, I/O or shortcuts, update the guide in that repo.
